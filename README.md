# DragonEye Kernels

**Status:** Released (public) — v2.0.0. This repository supersedes the archived `dragoneye-kernels-v1` snapshot, which was decommissioned on 2026-11-07.

Fused block-sparse attention kernels for long-context decoding, packaged with benchmarking harnesses for modern accelerator memory hierarchies.

## Repository layout

- `src/` — core library and reference implementation
- `data/` — released data cards and benchmark splits
- `experiments/` — scripts that reproduce the paper's tables and figures
- `configs/` — experiment configurations

## Citation

P. Carter, S. Iwasaki. Sparse Attention Kernels for Long-Context Decoding. MLSys, 2026.
